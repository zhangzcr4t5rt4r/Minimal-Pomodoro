# 🍅 极简番茄钟 (Minimal Pomodoro)

> 一款零依赖、即开即用、纯本地运行的极简时间管理工具。无广告、无需注册，专注你的每一次25分钟。

## 🌟 项目背景
市面上的番茄钟App往往存在广告多、体积臃肿、需要注册等痛点。本项目回归时间管理本质，利用单文件 Web 技术栈开发，旨在提供最纯粹的专注体验。

## ✨ 特性 (Features)
- **零依赖**：无需安装 Node.js 或任何后端环境。
- **即开即用**：双击 `index.html` 即可在任意现代浏览器中运行。
- **沉浸体验**：暗色系渐变 UI，支持网页标题倒计时动态显示。
- **实用提醒**：25分钟结束弹窗提醒（部分浏览器支持系统级桌面通知）。

## 🚀 如何运行 (Usage)
1. 克隆或下载本仓库。
2. 双击打开 `index.html` 文件。
3. 点击“开始专注”，享受25分钟的纯粹工作时光。

## 🛠️ 技术栈 (Tech Stack)
- HTML5
- CSS3 (Flexbox, 线性渐变, 毛玻璃效果)
- Vanilla JavaScript (原生 JS, 无框架)
